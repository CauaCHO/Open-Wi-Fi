# Open Wi-Fi

Plataforma de gestão de hotspots com Cloudflare Workers + D1 + R2, MikroTik RouterOS e Mercado Pago PIX.

O desenvolvimento ativo está sendo organizado por versões/branches. A próxima evolução do painel é a v1.3 com experiência de plataforma SaaS e provisionamento MikroTik consolidado.
